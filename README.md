# Yuzzy-Visa-Support

Public marketing site for Yuzzy Visa Support (EB1A, O1, and NIW profile building).

## Getting started

```bash
pnpm install
cp .env.example .env.local
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000). Set `NEXT_PUBLIC_CALENDLY_URL` and run `pnpm convex` when you are ready to connect booking and forms.
